# THƯ MỤC TÀI LIỆU ĐẶC TẢ MODULE (MODULE SPECS)

Thư mục này chứa toàn bộ các bản đặc tả kỹ thuật (Specification Contracts) cho từng module trong hệ thống.

## Quy Tắc Cho AI:
1. Khi tạo module mới: BẮT BUỘC tạo file `docs/modules/<tên_module>.md` dựa trên template tại `.agent/templates/module_spec_template.md`.
2. Khi sửa hoặc mở rộng tính năng: BẮT BUỘC đọc file spec của module đó trước để nắm vững ranh giới thiết kế.
3. Nếu thay đổi Public API hoặc Payload: Phải cập nhật tài liệu spec đồng thời với code.
